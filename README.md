# Multi-Line Insurance Policy and Claims Management System

Salesforce project for managing Vehicle, Property and Life insurance policies and claims.

## Milestones
1. Data Model & Policy Management
2. Quoting & Policy Automation
3. Claims Adjuster LWC Dashboard
4. Claims Approval, Integration & Testing

## Technology
- Salesforce Custom Objects
- Record Types and Field Sets
- Screen Flows
- Record-Triggered Flows
- Approval Process
- Apex / SOQL
- Lightning Web Components
- Apex Test Classes

## Important
Create the Salesforce objects and fields first. The Apex classes in this repository assume these API names:
- Policy__c
- Claim__c
- Customer__c
- Policy__c.Policy_Type__c
- Claim__c.Claim_Amount__c
- Claim__c.Severity__c
- Claim__c.Status__c
- Claim__c.Approval_Status__c
- Claim__c.Adjuster__c
